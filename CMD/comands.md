## Comandos de ayuda para sistema Windows

# Siempre abrir el panel de comandos con Windows + R

- Regedit: Abrir el editor de texto para modificar archivos de configuración del sistema.

- temp: Abrir la carpeta de archivos temporales del sistema.
- %temp%: Abrir la carpeta de archivos temporales del usuario.
- cleanmgr: Abrir la herramienta de limpieza de disco.
