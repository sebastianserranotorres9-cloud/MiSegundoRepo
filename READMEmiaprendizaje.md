## Comandos principales

|Comando| Funcion|
|-------|--------|
|git add .| cargar al stage|
|git commit | crear commit|
|git push |cargar mi trabajo creado|
|git pull | jalar mi trabajo al repositorio local|
|git merge| fusionar ramas|
|git checkout -b| crear rama|

## Flujo de trabajo

1. Crear Issue 
2. Crear Rama
3. Hacer pull a la rama
4. Trabajar en el issue 
5. Add . && commit && push
6. Pull request
7. Code review
8. Aprobar 
9. Close issue en el PR 
10. Merge
11. Delete Branch
